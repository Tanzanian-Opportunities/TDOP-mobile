# TDOP Mobile

**Tanzania Digital Opportunity Platform (TDOP)** — mobile application (planned).

## Status

**Planned.** No code exists yet and the technology stack is intentionally
**not decided** (see `TDOP-docs/PROJECT_MANAGEMENT.md` — stack choices are
recorded as decisions when the phase that owns them starts; nothing is invented
ahead of time).

## What this repository will hold

- The TDOP mobile client for opportunity seekers (browse, search, apply, track,
  notifications) once the corresponding phase begins.
- Its own README with the chosen stack, setup, and test commands at that time.
